# 🚀 .Wallet — Controle de Finanças Pessoais (Web App)

Este repositório reúne o desenvolvimento evolutivo de um sistema de gerenciamento de finanças pessoais, criado para fins acadêmicos e como parte da minha trajetória de aprendizado em desenvolvimento web.

## Estrutura do projeto
V1 — Vanilla JavaScript (vanilla-js)

Primeira versão da aplicação, desenvolvida com HTML, CSS e JavaScript puro. O foco está na manipulação do DOM, organização do código e fundamentos do desenvolvimento frontend.

V2 — React (react-js)

Refatoração completa da interface utilizando React. Nesta etapa, a aplicação passa a ser baseada em componentes, gerenciamento de estado e conceitos de Single Page Application (SPA).

V3 — Arquitetura Cliente-Servidor (react-client + express-api)

Versão full stack da aplicação, com separação entre frontend e backend. O cliente é desenvolvido em React, enquanto o servidor utiliza Express.js para fornecer uma API REST, autenticação com JWT e persistência de dados em PostgreSQL.

## Objetivos
Demonstrar a evolução de uma mesma aplicação em diferentes abordagens de desenvolvimento.
Consolidar conhecimentos em frontend e backend.
Aplicar conceitos de arquitetura, organização de código e escalabilidade.
Servir como projeto de estudo e portfólio.
